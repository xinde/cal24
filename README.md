# 24点 · 极智卡牌 (Make 24)

> 在线体验: https://xinde.github.io/cal24/

一个可直接部署到 **GitHub Pages** 的零依赖纯前端「计算 24 点」卡牌游戏。
用 4 张扑克牌, **分步计算**: 每次选两个数字和一个运算符得出结果, 结果自动投入数字池继续参与运算, 直到凑出 24。

## 玩法 (分步计算)

不需要写复杂算式, 也不需要括号, 一步步来:

1. 点击 **发牌**, 4 张牌飞入数字池
2. **选中两个数字** (第 1 个青色高亮, 第 2 个品红高亮)
3. 点击 **运算符** (＋ － × ÷), 结果立刻弹出, 自动投入数字池
4. 重复直到只剩 1 个数字
5. 若结果 = **24**, 点击 **提交答案** 锁定成绩!

> 例: 9,5,7,1 -> `9 − 5 = 4` (池: 4,7,1) -> `7 − 1 = 6` (池: 4,6) -> `4 × 6 = 24`

## 功能特性

- **自动发牌**: 每局随机发 4 张牌 (A 到 10, 不含 J/Q/K), 内置求解器保证 **每局必有解**
- **分步计算**: 选 2 个数字 + 运算符, 结果(含分数如 8/3)精确投入池中
- **可回退**: 点击历史步骤可回退到任意一步, 或一键撤销
- **双计时模式**:
  - `计时模式`: 记录每局用时, 保存 **历史最佳**
  - `挑战模式`: 90 秒倒计时, 最后 5 秒心跳滴答
- **绚丽特效**:
  - **出牌**: 纸牌从空中聚拢飞入、落地翻转、金色火花 + 冲击波迸发
  - **每步结果**: 结果筹码弹出 + 火花 + 冲击波
  - **答对**: 全屏彩带礼花 + 金色闪光 + 胜利音效
  - **公布答案**: 金色辉光横幅, 卡牌呼吸发光
- **智能提示**: 高亮解法关键一步涉及的两个数字 (每局 2 次)
- **音效引擎**: 纯 WebAudio 合成, 零音频资源, 可一键静音
- **键盘支持**: `1-9` 选数字 · `+ - * /` 运算符 · `Enter` 提交 · `Backspace` 撤销 · `Space` 发牌 · `Esc` 取消选中
- **响应式**: 桌面 / 平板 / 手机 (320px) 全适配, 支持减弱动态效果
- **无障碍**: 全 SVG 图标, 无 emoji 依赖, 支持屏幕阅读器

## 本地运行

无需构建, 任意静态服务器即可:

```bash
python3 -m http.server 8000   # 或 npx serve .
```

打开 <http://localhost:8000>。

## 部署到 GitHub Pages

已部署: <https://xinde.github.io/cal24/>

```bash
git push origin main

gh api --method POST repos/{owner}/{repo}/pages \
  -f "source[branch]=main" -f "source[path]=/" --silent
```

## 求解器

`js/solver.js` 使用**精确分数运算**避免浮点误差 (如 `8 / (3 - 8/3) = 24`),
穷举 4 张牌的全部排列 × 括号结构 × 运算符组合, 将最简洁的解排在前面。
每步运算的结果 (含分数) 通过同一套有理数精确表示, 保证不出现精度问题。
