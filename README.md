# 24点 · 极智卡牌 (Make 24)

一个可直接部署到 **GitHub Pages** 的零依赖纯前端「计算 24 点」卡牌游戏。
用 4 张扑克牌, 通过 **加 / 减 / 乘 / 除** 和 **括号** 凑出 24, 比拼手速与最强大脑。

![部署](https://img.shields.io/badge/部署-GitHub%20Pages-blue)

## ✨ 功能特性

- 🂠 **自动发牌**: 每局随机发 4 张扑克牌 (A 到 K), 内置求解器保证 **每局必有解**
- ⏱ **双计时模式**:
  - `计时模式`: 记录每局用时, 保存 **历史最佳**
  - `挑战模式`: 90 秒倒计时, 紧张刺激, 最后 5 秒心跳滴答
- ✨ **绚丽特效**:
  - **出牌**: 纸牌从空中聚拢飞入、落地翻转、金色火花 + 冲击波迸发
  - **答对**: 全屏彩带礼花 + 金色闪光 + 胜利音效
  - **公布答案**: 金色辉光横扫, 答案逐字闪耀, 卡牌呼吸发光
  - 错误算式: 抖动 + 红色警示
- 💡 **智能提示**: 一键提示关键一步 (每局 2 次)
- 🔊 **音效引擎**: 纯 WebAudio 合成, 零音频资源, 可一键静音
- ⌨️ **键盘支持**: 数字 1-9 插入牌, `+ - * / ( )` 运算符, `Enter` 提交, `Space` 发牌, `Esc` 清空
- 📱 **响应式**: 桌面 / 平板 / 手机 (375px) 全适配, 支持减弱动态效果

## 🎮 玩法

1. 点击 **发牌**, 4 张牌飞入牌桌
2. 点击牌面 + 运算符按键 (或直接敲键盘) 拼出算式
3. 点击 **提交**, 用尽可能短的时间凑出 24
4. 卡住时点 **提示**, 或直接 **公布答案**

## 🚀 本地运行

无需构建, 任意静态服务器即可:

```bash
# 任选其一
python3 -m http.server 8000
# 或
npx serve .
```

然后打开 <http://localhost:8000>。

## ☁️ 部署到 GitHub Pages

本仓库为纯静态站点, 可直接部署:

```bash
# 推送到 GitHub
git add .
git commit -m "feat: 24点卡牌游戏"
git push origin main

# 开启 GitHub Pages (main 分支 / 根目录)
gh api --method POST repos/{owner}/{repo}/pages \
  -f "source[branch]=main" -f "source[path]=/" \
  --silent
```

部署完成后访问 `https://<你的用户名>.github.io/<仓库名>/`。

```
    └── game.js       # 游戏主逻辑 (发牌/计时/提交/提示/公布)
```

## 🧮 求解器

`js/solver.js` 使用**精确分数运算**避免浮点误差 (如 `8 / (3 - 8/3) = 24`),
穷举 4 张牌的全部排列 (24 种) × 括号结构 (5 种) × 运算符组合 (64 种),
并将 **最简洁** 的解 (少除法 / 少括号) 排在前面作为答案与提示来源。
